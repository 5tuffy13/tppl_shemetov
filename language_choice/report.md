### 1) Обработка больших данных в реальном времени

**Парадигма** - Императивное программирование

**Язык** - Rust

**Обоснование** - Rust по скорости не уступает C и C++, но при этом обеспечивает безопасность при работе с памятью устройства. Так же в нем есть нативная поддержка параллельных вычислений. Императивный подход дает прямой контроль над состоянием и последовательностью инструкций, что дает преимущество в скорости работы программы, а для real-time это важно.

### 2) Прототип ML-сервиса для прогноза погодных условий

**Парадигма** - ООП

**Язык** - Python

**Обоснование** - в основе ml обучения на python библиотеках (pytorch, tensorflow) лежит ооп для удобного подбора архитектуры и параметров при обучении. Python был выбран для удобной итерации и смены алгоритмов при необходимости и для быстрого запуска mvp

### 3) Интерактивный UI для торгового терминала

**Парадигма** - декларативное + реактивное программирование

**Язык** - Typescript

**Обоснование** - Typescript компилируется в чистый JS, поэтому он не уступает ему в скорости, но в отличие от JS у него статическая типизация, которая упрощает тестирование. Выбор указанных парадигм это стандарт для работы с веб-приложениями:
декларативный подход упрощает написание логики работы, а рекативный позволяет ускорить работу интерфейса.


### 4)Прошивка для устройства регистрации температуры

**Парадигма** - Императивное программирование

**Язык** - C

**Обоснование** - в условиях real-time выполнения и ограниченного объема памяти нужно использовать как можно более низкоуровневый язык. Ассемблер подошел бы, если бы не важность переносимости кода. Поэтому логично использовать C. В сочетании с подходом императивного программирования программа на этом языке будет быстрой и легковесной.
